## 🌿 About Me

시스템·네트워크 엔지니어로서 인프라와 기술의 안정성을 다루는 동시에,
명상가이자 고양이 집사로서 마음의 균형과 따뜻함을 추구합니다.

현재는 **AI 부트캠프**를 통해 인공지능의 본질과 응용 기술을 탐구하며,
미래에는 AI 엔지니어로 성장해 **기술과 인간의 조화**를 이루는 솔루션을 만들고 싶습니다.
